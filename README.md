# Portfolio PBP — Lisya Ayu Mutiara Ramadhani

## WAJIB DIISI DULU (NIM & Kelas)
- Web: buka `script.js`, ubah `PROFILE.nim` dan `PROFILE.kelas` di baris paling atas.
- Desktop: buka `AppDesktop.java`, ubah konstanta `NIM` dan `KELAS`.

## Foto (opsional)
Taruh foto bernama `foto.jpg` di folder yang sama dengan `index.html`. Otomatis tampil di bagian "Tentang".
Jika tidak ada, tampil monogram "LA".

## Web
Buka `index.html`, atau deploy ke GitHub Pages (upload `index.html`, `style.css`, `script.js`, `foto.jpg`).

## Desktop (Java Swing)
```
javac -encoding UTF-8 AppDesktop.java
java AppDesktop
```
Jalankan dari folder yang berisi `index.html` agar tombol membuka file lokal (tanpa XAMPP).
